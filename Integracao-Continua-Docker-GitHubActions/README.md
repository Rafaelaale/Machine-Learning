# Integração Contínua com Docker e GitHub Actions

Material de estudo e implementações práticas do curso
**Integração Contínua com Docker e GitHub Actions:
do build ao deploy em nuvem**, da Alura.

## Conteúdo

- Python e Flask
- Quatro microserviços da Burger App
- Docker e Docker Compose
- MongoDB
- GitHub Actions
- Testes automatizados
- Docker Hub e GitHub Container Registry
- AWS ECS e Fargate
- AWS Lambda
- Segurança de pipelines e gerenciamento de Secrets
- Trivy e análise de vulnerabilidades
- Versionamento de imagens
- Estratégias de rollback
- Prometheus e Grafana
- Scripts PowerShell
- Anotações, validações e relatórios das aulas

## Estrutura

- `docker-automation/`: código-base e exercícios práticos
- `aulas/`: configurações e materiais produzidos durante o curso
- `scripts/`: automações e validadores
- `relatorios/`: resultados de análises locais

## Origem do material

Exercícios desenvolvidos durante o curso da Alura.

O projeto-base Docker Automation foi disponibilizado
pelo instrutor no repositório:

https://github.com/Danilo-Miguel/docker-automation

O material original pertence aos respectivos autores;
a atribuição não substitui eventuais permissões de uso.

## Estado das implementações

As validações locais realizadas estão documentadas nos arquivos.

A execução remota dos pipelines e os testes com AWS,
Grafana, Prometheus e Docker dependem da configuração
dos respectivos ambientes.

Os arquivos de estudo não incluem credenciais reais
nem ambientes virtuais.
