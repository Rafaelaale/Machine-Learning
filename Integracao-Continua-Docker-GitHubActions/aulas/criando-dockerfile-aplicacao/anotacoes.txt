AULA - CRIANDO UM DOCKERFILE PARA APLICACAO

Comando Linux apresentado pelo professor:
touch Dockerfile

Equivalente no PowerShell, caso o arquivo nao exista:
New-Item -ItemType File -Name Dockerfile

Listar arquivos:
ls

FROM - imagem base.
WORKDIR - diretorio de trabalho.
ENV - variaveis de ambiente.
RUN - instalacao de dependencias.
COPY - copia arquivos para a imagem.
EXPOSE - documenta as portas.
CMD - comando padrao de inicializacao.

ETAPAS DO MULTI-STAGE BUILD
base - prepara o sistema e ferramentas.
builder - instala dependencias Python.
final - recebe dependencias e codigo.

PORTAS
5000 - auth-service
5001 - user-service
5002 - order-service
5003 - product-service
