AULA - INTEGRANDO MONGODB AO DOCKER COMPOSE

DOCKERFILE DO PROFESSOR:
FROM mongo:6.0
COPY ./init-mongo.js /docker-entrypoint-initdb.d/

SCRIPT DE INICIALIZACAO:
db = db.getSiblingDB('burguer_app_db');
db.createUser({
    user: 'appuser',
    pwd: 'apppass',
    roles: [{ role: 'readWrite', db: 'burguer_app_db' }]
});

RECURSOS DO COMPOSE:
services
build
environment
volumes
networks
healthcheck
depends_on

CONFIGURACAO DESTA AULA:
MongoDB disponivel internamente como mongo:27017.
Volume exclusivo para persistencia de dados.
Quatro microservicos configurados com MONGO_URI.
Inicializacao condicionada ao healthcheck do banco.

ARQUIVO COMPOSE ORIGINAL PRESERVADO.
MONGODB EXISTENTE PRESERVADO.
