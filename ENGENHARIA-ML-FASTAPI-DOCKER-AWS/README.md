# Engenharia de Machine Learning

Curso Alura:
Projeto de engenharia de machine learning:
repositório, Docker e deploy na AWS com FastAPI.

## Objetivos

- Organizar um projeto de engenharia de ML.
- Desenvolver uma API usando FastAPI.
- Trabalhar com modelos de Machine Learning.
- Utilizar Docker para conteinerizacao.
- Estudar deploy na AWS.
- Implementar testes e documentacao.

## Ambiente

Python 3.11
VS Code
PowerShell

## Diretrizes

Projeto novo e independente.
Cada aula tera seus proprios arquivos.
Executar e validar cada etapa antes de continuar.

AWS: priorizar alternativas locais e gratuitas.
Deploy na nuvem somente apos verificar custos.
