# Aula 05 - Cenario hospitalar

## Pergunta do projeto

Como utilizar dados historicos para estudar fatores
associados a presenca de doenca cardiaca?

## Dataset

Heart Failure Prediction Dataset
918 registros segundo o material da Alura.

## Variavel alvo

HeartDisease
0 = ausencia
1 = presenca de doenca cardiaca

## Fase 1 - Ciencia de Dados

1. Explorar os dados.
2. Tratar dados faltantes e inconsistentes.
3. Analisar a distribuicao das classes.
4. Separar treinamento e teste.
5. Treinar um modelo de classificacao.
6. Avaliar precision, recall, F1 e matriz de confusao.

Alternativa local ao SageMaker:
Python, Pandas e Scikit-learn.

## Fase 2 - Engenharia de Dados

1. Receber arquivos CSV.
2. Transformar e validar dados.
3. Padronizar os registros.
4. Consultar os dados com SQL.

Alternativas locais:
Python, DuckDB e, se necessario, PySpark.

## Limites de utilizacao

Projeto exclusivamente educativo.
Nao usar previsoes para diagnostico ou atendimento real.
Nao incluir dados identificaveis de pacientes.

## Custo

Sem recursos AWS criados.
Sem cobrancas de nuvem.
