# Responsabilidades e manutencao

## Desenvolvimento educacional

O projeto esta sendo implementado como estudo
pratico do curso da Alura.

## Responsaveis organizacionais

Nao ha equipes de producao ou responsaveis
corporativos formalmente designados.

Em uma aplicacao corporativa, definir:

| Atividade | Responsavel |
|---|---|
| Objetivos de negocio | A definir |
| Qualidade dos dados | A definir |
| Treinamento e avaliacao | A definir |
| Implantacao | A definir |
| Monitoramento | A definir |
| Incidentes | A definir |
| Privacidade e governanca | A definir |

## Atualizacao da documentacao

Revisar quando houver mudanca de:

- Esquema de dados.
- Regras e transformacoes.
- Versoes de dependencias.
- Modelo ou metricas.
- Interfaces e procedimentos.
- Responsabilidades.
- Condicoes de uso.

## Registro de problemas

Registrar:
- Descricao e impacto.
- Evidencias e testes.
- Causa identificada.
- Correcao aplicada.
- Validacao posterior.
