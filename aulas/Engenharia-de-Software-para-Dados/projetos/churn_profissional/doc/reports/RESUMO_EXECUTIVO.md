# Resumo executivo - Projeto Churn

## Problema

O cenario da Alura apresenta um e-commerce
cujo modelo de identificacao de abandono
de clientes precisa ser revisado.

## Trabalho realizado

- Analise do codigo existente.
- Aplicacao de boas praticas de Python.
- Organizacao profissional das pastas.
- Separacao de responsabilidades.
- Criacao de pacote de pre-processamento.
- Testes automatizados dos componentes.

## Dados

10.000 registros no dataset de estudo da Alura.

## Resultado observado do modelo

Accuracy: 69,8%.

Recall de churn: 0%.

O modelo nao identificou corretamente os casos
positivos de churn no conjunto de teste.

## Conclusao para o negocio

O desempenho atual nao sustenta a utilizacao
do modelo para identificar clientes em abandono.

## Proximas necessidades

1. Investigar o comportamento das classes.
2. Avaliar metricas de identificacao de churn.
3. Revisar atributos e transformacoes.
4. Definir criterios de aceitacao com o negocio.
5. Validar o modelo antes de qualquer implantacao.

## Situacao

Projeto de estudo. Nao implantado em producao.
