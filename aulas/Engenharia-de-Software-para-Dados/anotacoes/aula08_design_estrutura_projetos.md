# Aula 08 - Design e estrutura de projetos

## Objetivo

Compreender a organizacao profissional de
projetos de Ciencia de Dados e Machine Learning.

## Data

Centraliza dados brutos, processados e externos.

## Notebooks

Organiza experimentos e analises exploratorias.

## Tests

Armazena verificacoes automatizadas.

## SRC

Contem funcoes e scripts Python reutilizaveis.

## Models

Armazena artefatos de modelos treinados.

## DOC

Contem relatorios, apresentacoes e documentacao.

## Requirements

Declara as dependencias Python do projeto.

## Setup

Pode configurar a distribuicao do pacote Python.
Nao substitui a documentacao de infraestrutura.

## README

Explica objetivos, estrutura e uso do projeto.

## Engenharia de requisitos

Perguntas importantes:

- Qual problema de negocio sera resolvido?
- Quem utiliza as previsoes?
- Quais dados alimentam o modelo?
- Quem responde pela qualidade dos dados?
- Como as previsoes serao consumidas?
- Como garantir a reproducibilidade?
- Quais sao as restricoes do ambiente?
- Como acompanhar a qualidade do sistema?

## Experimentos

A Alura menciona ferramentas como MLflow
para acompanhar experimentos e modelos.

Nesta aula, apenas organizamos a estrutura.
Nao instalamos nem configuramos MLflow.

## Laboratorio

Criamos o subprojeto churn_profissional.

Utilizamos os 10.000 registros da Alura
e validamos a estrutura com Python.

Os codigos das aulas anteriores continuam
preservados no projeto principal.

## Aprendizado central

Design de projeto ajuda a manter o
software compreensivel, reutilizavel,
reproduzivel e preparado para crescimento.
