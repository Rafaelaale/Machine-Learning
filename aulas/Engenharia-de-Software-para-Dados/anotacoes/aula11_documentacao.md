# Aula 11 - Documentacao de codigo e projeto

## Objetivo

Aprender a documentar um projeto de Ciencia
de Dados desde a identificacao da demanda.

## Documentacao deve incluir

1. Problema de negocio.
2. Objetivos e contexto.
3. Usuarios e areas interessadas.
4. Estrutura do projeto.
5. Instalacao e guia de uso.
6. Origem e regras dos dados.
7. Tratamentos e limitacoes.
8. Responsaveis e monitoramento.
9. Licenciamento.
10. Resumo executivo.

## README

Arquivo principal de entrada da documentacao.

## Documentacao tecnica

Explica componentes, arquitetura, variaveis,
transformacoes e procedimentos de execucao.

## Resumo executivo

Documento breve para o negocio.

Destaca objetivos, resultados, limitacoes
e proximas decisoes.

## Manutencao

Documentacao precisa acompanhar mudancas
do codigo, dos dados e dos requisitos.

## Laboratorio

Criamos documentos para o projeto profissional
de churn e testes automatizados de consistencia.

## Observacao

Documentacao nao deve ocultar problemas.

Na Aula 07, o recall do modelo para
a classe churn foi zero.

Esse resultado precisa ser investigado
antes de qualquer uso operacional.
