de desenvolvimento.

## Pull request

Proposta de integracao de uma branch em outra.

## Code review

Revisao de codigo, comportamento, testes
e documentacao por outras pessoas.

Uma revisao reduz riscos, mas nao garante
que todos os problemas serao detectados.
