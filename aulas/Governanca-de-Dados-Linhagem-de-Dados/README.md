# Governança de Dados - Linhagem de Dados

## Curso Alura

Governança de dados: mapeando a origem e o destino
com linhagem de dados.

## Objetivo

Estudar e praticar o mapeamento da origem,
das transformações e do destino dos dados.

## Organização

- dados/: bases utilizadas
- metadados/: informações sobre os dados
- resultados/: saídas das atividades
- anotacoes/: teoria e conceitos
- tests/: testes das implementações
