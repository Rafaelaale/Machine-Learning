# Aula 02 - Exemplo matematico

## Equacao principal

V = Q(D)

- V: visao ou resultado.
- Q: consulta ou transformacao.
- D: conjunto de dados de origem.

## Equacao com varias origens

V = Q1(D1) + Q2(D2) + Q3(D3)

No exemplo do curso:

- D1: precos de imoveis por metro quadrado.
- D2: compras e vendas em cartorios.
- D3: analises anteriores do ativo.
- V: base resultante de avaliacao.

O sinal de adicao representa a combinacao
conceitual das contribuicoes das tres origens.

## Transformacoes SQL

Exemplos discutidos:

- SELECT
- JOIN
- GROUP BY
- ORDER BY

Uma VIEW permite consultar um resultado
logico derivado de outras tabelas.

## Aprendizado principal

A linhagem de dados pode ser representada
por expressoes que identificam as origens
e as transformacoes que geram um resultado.

A representacao abstrata nao precisa detalhar
todas as operacoes realizadas.
