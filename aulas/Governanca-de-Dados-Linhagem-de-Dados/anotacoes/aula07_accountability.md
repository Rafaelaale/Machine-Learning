# Aula 07 - Accountability

## Objetivo

Compreender a accountability como capacidade
de responder pelas responsabilidades associadas
ao uso dos dados.

## 1. Conceito

Accountability significa prestacao de contas.

No contexto organizacional, envolve responder
de maneira etica e correta pelas responsabilidades
assumidas no tratamento e uso dos dados.

## 2. Tipos de dados

A aula destaca responsabilidades relacionadas a:

- Dados internos.
- Dados externos.
- Dados pessoais.

Os dados pessoais exigem atencao especial
por envolverem a privacidade das pessoas.

## 3. Linhagem e accountability

A linhagem ajuda a demonstrar:

- A origem das informacoes.
- As transformacoes realizadas.
- Os processos que dependem dos dados.
- O historico necessario para auditorias.

A linhagem por coluna pode oferecer
rastreabilidade mais detalhada.

## 4. Auditoria

A linhagem contribui para auditorias
internas e externas, oferecendo evidencias
sobre o processamento das informacoes.

Ela nao garante conformidade automaticamente.

## 5. Investimento organizacional

A gestao da linhagem exige:

- Capacitacao das equipes.
- Ferramentas adequadas.
- Manutencao dos registros de linhagem.

## 6. Laboratorio complementar

Reutilizamos a documentacao da Aula 06.

Identificamos a cadeia de dependencias
desde SOR ate a especializacao final.

Geramos evidencias para um relatorio
didatico de prestacao de contas.

Nenhuma responsabilidade formal ou
conformidade juridica foi presumida.

## 7. Principal aprendizado

A linhagem de dados e uma ferramenta que
ajuda as organizacoes a prestar contas
sobre como os dados foram utilizados.

Accountability tambem depende de pessoas,
processos e controles organizacionais.
