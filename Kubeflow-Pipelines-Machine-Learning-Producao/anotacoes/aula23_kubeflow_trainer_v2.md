# Aula 23 — Kubeflow Trainer v2

## Objetivo
Conhecer o componente Trainer do Kubeflow.

## Training Jobs
Tarefas responsáveis por executar treinamentos de modelos.

## Runtimes
Ambientes que definem como o treinamento será executado.

## Treinamento distribuído
Permite distribuir o trabalho entre recursos computacionais.

## Integração com KFP
O Trainer pode ser integrado a pipelines de Machine Learning.
