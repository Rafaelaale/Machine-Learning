# Aula 04 - Instalacao do Minikube

## Objetivo
Criar um cluster Kubernetes local para Kubeflow.

## Ambiente
Windows com Ubuntu WSL2 e Docker Desktop.

## Requisitos do curso
- 10 GB de memoria disponivel para o ambiente
- 4 nucleos de CPU disponiveis
- 30 GB de disco livre
- Recomendados: 12 GB ou mais de memoria e 60 GB de disco

## Ferramentas
- Minikube
- kubectl
- kustomize
- uv
- Docker Desktop com integracao WSL2

## Componentes futuros
1. Kubeflow Pipelines
2. Katib
3. Kubeflow Trainer
4. cert-manager
5. KServe

## Versoes utilizadas no roteiro da Alura
- Kubernetes v1.29.0
- KFP 2.15.0
- Katib v0.18.0
- Trainer v2.1.0
- KServe v0.13.1
